# Business case: Example Supply returns agent
(synthetic numbers from ch23/roi_model.py, 2026-11-04)

## Ask
Approve go-live for all returns tickets. A person
still approves every refund.

## Baseline
- Tickets a month: 2,773
- Person cost per task: $6.52
Source: this engagement's baseline and control group.

## Cost per task
- Agent cost per task: $5.30
- Saving per task: $1.22
Both sides pay for handle time, repeat contacts, and wrong
refunds. The agent side adds a review sample and the model.

## Costs
- Build cost: $16,640
- Run cost a month: $1,150

## Break-even
- Break-even month: 9
- Net after 24 months: $34,749
Ramp: 50%, 80%, then all tickets.

## Risks
- Widest input: run cost a month, months 7 to 18
- Break-even with errors doubled: 21
Firm up the widest input before signing.

## Price
Fixed fee for the build: half at signed scope,
half at go-live. Run cost billed monthly at cost.

## Measures
Monthly: cost per task on both sides, repeat
contacts, wrong refunds, and the cumulative total against
this page. Stop if wrong refunds pass 1.25% of tickets.
