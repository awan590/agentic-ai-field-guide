# Alerts

## Alert list

- error rate: errors over 0.05, page
- slow replies: p95_s over 8.0, page
- token drift: tokens at 1.5 times the usual, ticket
- handoff drift: handoffs at 2.5 times the usual, ticket
- Wrong refunds past the stop line in the
  [business case](../business-case.md).

## Who is paged

The platform on-call lead first, then the backup in
[Owners](owners.md).
